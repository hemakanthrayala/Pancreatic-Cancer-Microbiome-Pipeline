# Pancreatic-Cancer-Microbiome-Pipeline
A practical 16S rRNA analysis guide detailing SRA data fetching, FastQC checks, and QIIME 2 import. It covers DADA2 denoising, phylogenetic tree building, alpha and beta diversity, SILVA classifier training, taxonomic collapsing, ANCOM biomarker discovery, and R-based visualization for PCoA and top genera bar plots.
