# Pancreatic-Cancer-Microbiome-Pipeline
A practical 16S rRNA analysis guide detailing SRA data fetching, FastQC checks, and QIIME 2 import. It covers DADA2 denoising, phylogenetic tree building, alpha and beta diversity, SILVA classifier training, taxonomic collapsing, ANCOM biomarker discovery, and R-based visualization for PCoA and top genera bar plots.
The pipeline utilizes the QIIME 2 framework alongside the SRA Toolkit (prefetch, fasterq-dump) and FastQC for raw data retrieval and quality control. Key tools and analytical parameters include qiime tools import with the PairedEndFastqManifestPhred33V2 format, paired-end denoising via dada2 denoise-paired (--p-trunc-len-f 280, --p-trunc-len-r 260), and phylogenetic tree reconstruction using phylogeny align-to-tree-mafft-fasttree. Taxonomic classification is conducted using a Naive Bayes classifier (feature-classifier fit-classifier-naive-bayes) trained on SILVA reference sequences trimmed to the V4 region with 515F/806R primers (GTGCCAGCMGCCGCGGTAA and GGACTACHVGGGTWTCTAAT). Downstream biomarker selection and statistics include taxonomic collapsing to genus level (--p-level 6), composition ancom, 999-permutation PERMANOVA via diversity beta-group-significance, supervised classification with sample-classifier classify-samples, and stacked abundance plotting in R using tidyverse and ggplot2.

Rather than serving as an automated terminal runtime trace with recorded system memory, CPU execution durations, or exit status codes, the log demonstrates an explicit command-line execution and protocol guide. It details step-by-step inputs across multiple sample accessions (SRRcode), quality checkpoints via visualisation artefacts (.qzv), conversion steps via biom-format, and convergence strategies—such as extracting unclassified biomarker feature sequences from rep-seqs.qzv to confirm species identities against NCBI BLAST.
